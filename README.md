# Signal Sprint — Landing Page

A one-page marketing site for [Signal Sprint](https://signal-sprint-1.vercel.app/), a live two-player race where friends on separate devices chase the same glowing signal.

## What's here

- `index.html` — the full single-page site (HTML + CSS, no build step, no dependencies)

## Run it locally

Open `index.html` in any browser. That's it.

## Hosted with GitHub Pages

This repo is published via GitHub Pages from the `main` branch.

## About the game

- Two players, one shared board, 60 seconds
- Host creates a room and shares a code; the opponent joins from anywhere
- Move with WASD or arrow keys; first runner to the signal scores it
- Most signals collected when the clock hits zero wins
